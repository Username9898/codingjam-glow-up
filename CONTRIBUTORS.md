## 🎖️ Recognition Tiers

### 🥇 Gold Tier
**Criteria**: 50+ significant commits OR architectural contributions

**Benefits**:
- Featured prominently in README.md
- Recognition page on website
- Lifetime attribution in code
- Revenue share opportunity (negotiable)

### 🥈 Silver Tier
**Criteria**: 10-49 commits OR multi-feature implementation

**Benefits**:
- Listed in CONTRIBUTORS.md
- GitHub profile link
- Special badge/emoji
- Early access to new features

### 🥉 Bronze Tier
**Criteria**: 1-9 commits OR 1-2 substantial features

**Benefits**:
- Listed in CONTRIBUTORS.md
- GitHub profile link
- Mentioned in PR description

### 💙 Community Tier
**Criteria**: Reported bugs, suggestions, feedback

**Benefits**:
- Listed if requested
- Recognition in GitHub discussions
- Direct credit when issue resolved

## 📝 How to Add Your Name

### After Merging Your First PR
1. **Notify maintainers** in PR description or comment
2. **Suggest tier** based on your contribution
3. **Provide details**:
   - GitHub username
   - GitHub profile URL (optional)
   - Role/focus area
   - Contact info (optional)

### Or Create an Issue
If you've contributed but weren't automatically added:
1. Open a GitHub Issue
2. Title: "Add me to contributors"
3. Include contribution details
4. Maintainers will update this file
